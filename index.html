💾 Quản Lý Sao Lưu & Phục Hồi Dữ Liệu

Hệ thống đã tự động lưu trữ dữ liệu vĩnh viễn trên máy tính của bạn (LocalStorage). Để an toàn tuyệt đối khi chuyển máy hoặc bảo trì vá lỗi, bạn có thể xuất file sao lưu JSON hoặc nạp lại bất cứ lúc nào.

1. Xuất File Sao Lưu Hệ Thống (.JSON) Tải về máy toàn bộ: Bảng giá, Cấu thành mẻ BTP, Menu định lượng món.
2. Nạp Lại File Sao Lưu (Restore) Phục hồi dữ liệu nguyên vẹn từ file sao lưu JSON đã lưu trước đó.
3. Khôi Phục Dữ Liệu Mẫu Mặc Định Xóa dữ liệu hiện tại và khôi phục lại bộ công thức & giá mẫu gốc.

📥 Nạp Công Thức Định Lượng Menu (File CSV / Excel)

Phương án nạp hàng loạt công thức menu từ file template Excel/CSV. Hệ thống sử dụng chung 1 nguồn Bảng Giá Nguyên Liệu & Mẻ BTP để tự động điền đơn vị và tính toán giá vốn chính xác cho từng ly nước!

📋 QUY TẮC ĐỊNH DẠNG FILE TEMPLATE (7 CỘT CHUẨN):
1. Tên Món: Tên hiển thị trên menu (ví dụ: Trà Sữa Olong Nướng BFresh)
2. Danh Mục: Nhóm món (ví dụ: Trà Sữa, Trà Trái Cây, Cà Phê... - Tự tạo nhóm mới tùy ý)
3. Size: Size ly (ví dụ: Size M, Size L, 500ml, 700ml...)
4. Giá Bán: Giá bán niêm yết tại quán (ví dụ: 35000)
5. Nhóm Thành Phần: Điền 1 trong 3 nhóm: Mẻ (hoặc BTP), Nguyên Liệu, Bao Bì
6. Tên Thành Phần: Tên nguyên liệu thô hoặc Mẻ (khớp với Bảng Giá hoặc Mẻ đã tạo)
7. Định Lượng / Ly: Khối lượng sử dụng cho 1 ly nước (ví dụ: 120, 30, 1...)
💡 Mẹo: Các dòng có cùng Tên Món + Size sẽ được hệ thống tự động gom lại thành 1 thẻ món hoàn chỉnh trong Menu!
1. Tải File Mẫu Chuẩn (Excel / CSV) File mẫu chuẩn 1 Sheet dạng Thẻ Khối, đã có sẵn 5 Mẻ cốt & 7 Món trà trái cây nhiệt đới chuẩn R&D.
